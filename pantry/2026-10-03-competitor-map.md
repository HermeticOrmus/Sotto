## Product frame

Sotto is **not** a dictation app with a chat box, and it is **not** an IDE. It is a **desktop control surface for the coding-agent CLIs you already have** (Claude Code, Codex, Grok Build, Devin). Every thread sits in one sidebar, and **you answer every request** the thread's permissions don't already allow. **Dictation is built in** (`Ctrl+Shift+Space`). Remote **SSH hosts** run a headless Sotto host. A paired **iPhone** (in development) can reach the threads over your own tailnet. It is free, MIT, in beta, and has no account and no telemetry. Windows x64 is the first platform and Apple-silicon macOS the second (`AGENTS.md`). The domain glossary describes it as a "dictation app that is becoming a voice development coordinator" (`CONTEXT.md`). Its Git design follows T3 Code on purpose (ADR-0027 "git the way T3 Code does it").

### Capability column definitions

- **Multi-vendor agents**: one app drives coding agents from two or more vendors (for example Claude Code and Codex)
- **BYO CLI sign-ins**: uses the CLIs and subscriptions you already signed in to, not a new account that resells inference. P = only the vendor's own login
- **Windows desktop / Linux desktop**: a released desktop build for that OS (P = experimental). Sotto's headless host on Linux does not count as a desktop
- **Parallel worktrees**: several agents work in isolated Git checkouts of one repo
- **Git → PR in app**: commit, push and open a pull request without leaving the app (P = some of it)
- **In-app browser / preview**: a browser or app preview pane the agent or you can use inside the app (P = preview or browser tabs only, or access settings without a documented pane)
- **Integrated terminal**: a terminal inside the app (Claude Squad is itself a terminal app)
- **Remote hosts you own**: agents run on another machine of yours (SSH or a paired host) and the app drives them. Vendor cloud sandboxes do not count (P = paid tier only, or phone-to-own-machine only)
- **Phone client**: a phone app that reaches the threads (P = paid tier only)
- **Built-in dictation**: speech-to-text inside the product (P = only in a sibling surface, such as the Claude Code CLI's `/voice`)
- **OSI open source**: source under an OSI licence (ELv2 = N, source-available)
- **Free core**: the local desktop product is usable for free (P = free tier with limits)
- **No telemetry by default**: the product says it sends no analytics by default (N = opt-out telemetry)

## Notes for Diego

- **Product frame (proposed for lock):** a desktop control surface for the agent CLIs you already have, with dictation built in and every request answered by you. It is not an IDE and not a dictation utility. Closest verified peer: **T3 Code**. Same-thesis peers: **Conductor**, **Emdash**, **Superset**, **Nimbalyst**. Vendor-native rivals: **Codex app**, **Claude Code Desktop**, **Cursor Agents Window**. Dictation rivals: **Wispr Flow**, **Superwhisper**, **VoiceInk**, **Handy**.
- **Sotto's open lane:** it is the only multi-vendor agent GUI in this map that combines **built-in dictation**, a **Windows-native** build, **SSH hosts you own** and **no telemetry by default** under MIT. T3 Code, the closest peer, explicitly declined voice input. Conductor has voice but is Mac-only and paid for mobile and remote.
- **The base is commoditising:** Codex app, Claude Code Desktop and Cursor 3 all ship worktrees, Git→PR, previews and phone control in 2026. Sotto's case rests on the cross-vendor sidebar, voice and privacy, not on worktrees.
- **Biggest gaps:** Linux desktop (T3, Emdash, Nimbalyst, Cursor, Handy have it), Android and a shipped phone app (T3, Happy, Codex, Claude), provider breadth, issue intake and automations (Emdash, Superset, Codex), and offline dictation (Handy, VoiceInk, Superwhisper).
- **Market motion:** Vibe Kanban is sunsetting and Crystal is deprecated (→ Nimbalyst). Paid tiers gate mobile and remote (Conductor Pro $50/mo, Superset Pro $20/mo).
- Peer count this run: **15**. Matrix cell flips: n/a (first run).
- X mine next: reactions keyed to matrix columns (dictation latency/accuracy, approvals, worktrees on Windows, phone remote, multi-vendor, telemetry), not brand vibes. **Do not invent X hits.**
- **Upstream boundary:** Sotto is Zach's product. Any atom that changes app code ships on `ormus` first. Whether it is offered upstream to `millZach/Sotto` is Diego's call, and merging it is Zach's.
