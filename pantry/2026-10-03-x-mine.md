## How this fills

1. Take top 5–8 names from the latest competitor map.
2. Search X for praise and complaints tied to **named matrix capabilities** (reliability, cost, DX, permissions, memory, multi-agent, verify), not brand vibes alone.
3. Fetch primary posts; quote short snippets with `x.com` links. **Never invent engagement counts or sentiment %.**
4. Save as `YYYY-MM-DD-x-mine.md` (keep this TEMPLATE).

## Notes for the queue

- **Phone + voice together is asked for and is still scarce.** @AlexFinn wants a phone-started remote session that he can talk to. @Nothing_Poetics says Codex is "the only thing that provides it and the Voice assistant". Sotto has dictation and a paired iPhone in development. This is the open lane the competitor map named.
- **"Any CLI" on the phone.** @MobileCLI ("This but for any CLI") and @arnvbnsl ("other models from other providers/harnesses") back Sotto's multi-vendor sidebar, and they argue for adding providers.
- **Vendor speech-to-text is judged against local models.** @z33b0t says Claude's app STT is "Worse than open source whisper, than Parakeet". @thiagotm praises local Whisper for latency and privacy, and @AdamTzag recommends Parakeet. This backs the offline dictation ADR.
- **Phone state has to be honest.** @bygodgiven: "If the phone lies about state once, you stop trusting it entirely." @kienbuilds and @dranben report reliability and queueing failures in a vendor phone client.
- **Attach to sessions you already have.** @TheRealAfroRick wants "any arbitrary session on my machine", and @xenognostic does it by hand with tmux. This matches @sudoTomas's millZach/Sotto#669 (see the people mine).
- **Linux:** "When Linux?" on the Codex Windows launch, and "the only solution for Linux" for T3 Code.
- **Windows:** praise for native Windows (no WSL), and complaints about WSL, first launch and Store-only installs. Sotto already ships a direct Windows x64 build, so this confirms the shipped baseline and is not a new atom.
